=== 1. PROJECT GOAL ===
A single-page portfolio for Yildiz Dikme (Creative Developer / Technology Creator). It opens as a cinematic aviation sequence and then becomes a normal, usable site.

The visitor lands on a dark cabin wall with a small aeroplane window in the centre. Scrolling enlarges that window until the frame leaves the viewport and the visitor has passed THROUGH it into a full-screen cloud field. A WebGL circular gallery of work then rises from below the viewport into the upper band of the screen, stays there, keeps advancing as the page scrolls, and can be dragged left/right with the mouse. The hero's editorial statement enters underneath it. The hero then unpins into a second pinned scene where a 3D business jet flies up through the frame while the background fades from pale blue to near-black. Below that, three quiet editorial sections on that same near-black surface — services, a project enquiry brief, and a community/membership presentation — and finally a dark footer with an interactive globe.

Two visual registers, one codebase:
- CINEMATIC (pinned, scroll-scrubbed): the aperture hero and the jet outro. Cold blue-white palette, display serif, no UI chrome.
- FUNCTIONAL (normal document flow): services / enquiry / community / footer. Near-black surface, hairline rules, the same serif at smaller sizes. No cards, no panels, no shadows.

Responsive at 900px (isMobile = matchMedia("(max-width: 900px)")) plus CSS breakpoints at 1000px, 900px, 700px, 600px.

=== 7. THE HERO — EXACT GEOMETRY AND TIMELINE (load-bearing) ===
DOM order inside `<section className="hero">` matters for BOTH paint order and hit-testing:
  1. .hero-fade          bottom gradient into the jet scene, z-index 999, pointer-events none
  2. .sky-container      position RELATIVE (not absolute), height 350svh — the scrolling cloud plate
  3. .hero-gallery       the WebGL gallery overlay, z-index 0
  4. .hero-copy          the editorial statement
  5. .window-container   the window plate, height 100svh
  6. .hero-header        name + positioning type, height 100svh, transform-style preserve-3d
`.hero` itself carries `perspective: 1000px` and `isolation: isolate`.

The gallery is placed BEFORE .hero-copy and given `z-index: 0` (not a positive value) so the copy always paints on top of it. It is placed BEFORE .window-container so the window plate paints over it — which is correct, because the glass is transparent and the frame then reads as framing the gallery during the reveal.

ONE ScrollTrigger:
  trigger .hero ; start "top top" ; end () => `+=${window.innerHeight * 5}px`
  pin true ; pinSpacing true ; scrub 1 ; invalidateOnRefresh true
`end` MUST be a function, not a template string. A static string is not recomputed on refresh, so resizing the window leaves the pin distance measured against the old viewport.

Constants:
  PIN_VIEWPORTS 5 ; APERTURE_VIEWPORTS 3 ; APERTURE_SCALE = 5/3
  COPY_START 0.78 ; FADE_START 0.78 ; FADE_SPAN 0.12

onUpdate(progress) writes five things:
  ap          = min(1, progress * 5/3)          // the original 3-viewport curve, replayed over the first 3 of 5
  windowScale = ap <= 0.5 ? 1 + (ap/0.5)*3 : 4  // 1 -> 4, complete at progress 0.30
  .window-container  scale windowScale
  .hero-header       scale windowScale, z ap*500     (flies past the camera through the 1000px perspective)
  .sky-container     y -progress * (skyHeight - innerHeight)   // NOTE: raw progress, not ap — the clouds keep drifting behind the gallery instead of freezing at 0.60
  .hero-copy         yPercent 100 until 0.78, then linear to 0 at 1.0
  .hero-fade         opacity clamp01((progress - 0.78) / 0.12)
  gallery handle     update(progress)

Why the ap remap exists: the pin was originally 3 viewports. Making it 5 gave the gallery room to be explored. Driving the window off `ap` replays the ORIGINAL curve over the first 3 viewports of the longer pin — identical scale, identical perspective, identical rate of travel in absolute scroll pixels — then holds at 4. Do not "simplify" this to raw progress; it changes the aperture's speed.

Before-anything-else in the same effect, immediately after `new Lenis()`:
  lenis.scrollTo(0, { immediate: true, force: true })  — once, then once more inside requestAnimationFrame
This is a reload guard, explained in PART B BUG 1.

Cleanup MUST cancel that rAF, `ctx.revert()`, `gsap.ticker.remove(raf)` and `lenis.destroy()`.

=== 8. THE CIRCULAR GALLERY BRIDGE (HeroCircularGallery.tsx) ===
This is NOT a page section. It is an overlay inside the pinned hero, and it owns NO ScrollTrigger. Hero calls `update(progress)` every scroll frame through an imperative handle.

Constants:
  ENTER_START 0.30      // aperture just finished; gallery still entirely BELOW the viewport
  ENTER_END   0.48      // fully in place
  ITEMS_TRAVELLED 5     // item-widths the vertical scroll advances after it lands
  DPR_DESKTOP 1.5 ; DPR_MOBILE 1

update(progress):
  slide = clamp01((progress - 0.30) / (0.48 - 0.30))
  wrapper.style.transform  = `translateY(${(1 - slide) * 100}svh)`   // POSITION ONLY
  wrapper.style.visibility = progress >= 0.30 ? "visible" : "hidden" // written only on change
  wrapper.style.pointerEvents = slide >= 1 ? "auto" : "none"
  if (visible && !reducedMotion):
    travel = clamp01((progress - 0.48) / (1 - 0.48))
    api.setScrollBase(travel * 5 * api.getItemWidth())

NON-NEGOTIABLE behaviours:
  - Opacity is 1 at ALL times and is NEVER animated. There is no fade-in and no fade-out.
  - There is no exit. Once revealed the gallery stays for the rest of the hero and leaves only when the hero itself unpins.
  - The entrance is a slide from fully below the viewport, exactly like .hero-copy — never a "pop" in the middle of the cloud scene.
  - The wrapper's CSS has `transition: none !important`. The visibility switch must never be interpolated.
  - The wrapper is anchored to the TOP of the viewport (`justify-content: flex-start` + `padding-top: calc(3svh + 33px)`), NOT centred. `.hero-copy` is a vertically centred block, so the only way to keep real clearance above it is to pin the gallery to the upper band. Measured clearance at a 1100px viewport: 207px.
  - The 33px in that padding compensates for a "SELECTED WORK" label that used to sit above the stage; it was removed and the padding keeps the cards at exactly the same height.
  - The renderer is mounted on the FIRST client render, not lazily. Nothing whatsoever is created once the visitor starts scrolling.
  - The gallery images are requested and `decode()`d in a mount effect, so they load behind the Loader.
  - `update()` touches inline styles and the imperative API only. It NEVER calls a React state setter — a setState per scroll frame is what caused a visible hitch during the aperture.

#######################################################################
PART B — COMMON REPRODUCTION FAILURES (the exact bugs to avoid)
#######################################################################

Every bug below was hit and fixed during the original build. They are listed in the order they cost the most time.

BUG 1 — ON RELOAD THE HERO OPENS ALREADY ZOOMED (window huge, no header type).
Cause: the browser restores the previous scroll offset on refresh, so the pinned hero starts part-way through its timeline. Three partial fixes that are NOT enough on their own:
  (a) `history.scrollRestoration = "manual"` inside a React effect — too late. Chrome RETRIES the restore as the document grows, and this page grows twice after hydration (the pin spacers, then PlaneOutro's pin once its 6 MB GLB resolves). The late retry lands after any reset a component performed.
  (b) `window.scrollTo(0, 0)` once Lenis is running — Lenis writes its own position back to the document every frame, so the reset is overwritten on the next tick.
  (c) locking the page with `overflow: hidden` while a loader is up — this collapses ScrollTrigger's pin distance to ZERO, which is a worse version of the same symptom (the hero freezes at the END of its timeline).
FIX, all three layers:
  1. An inline script in `<head>` (layout.tsx, via dangerouslySetInnerHTML) that runs BEFORE the body is parsed:
       try{history.scrollRestoration='manual';window.scrollTo(0,0)}catch(e){}
     This stops the restore from ever starting rather than trying to undo it.
  2. In Hero, immediately after `new Lenis()`: `lenis.scrollTo(0, { immediate: true, force: true })`, once synchronously and once inside `requestAnimationFrame`. The reset must go through Lenis, not the window.
  3. The Loader's layout effect repeats step 1 as a safety net, and does NOT lock scrolling.
VERIFY: set `history.scrollRestoration='auto'`, scroll to ~2600px, reload, then WAIT 2.5 s (so the GLB resolves and the late retry would fire). Expect scrollY 0 and window scale 1.

BUG 2 — THE GALLERY CANNOT BE CLICKED OR DRAGGED WITH A REAL MOUSE (yet synthetic events "work").
Cause: `.window-container` and `.hero-header` are full-viewport absolutely-positioned layers with the default `pointer-events: auto`. Real mouse events hit-test against them first and never reach the gallery canvas underneath. A synthetic `PointerEvent` dispatched directly onto the canvas bypasses hit-testing entirely, so a naive test reports success while the real pointer is blocked.
FIX: `.hero-copy, .window-container, .hero-header { pointer-events: none }`. All three are purely decorative — no links, no controls — so nothing on screen changes.
VERIFY with hit-testing, not synthetic events:
  document.elementsFromPoint(cx, cy)   // must start with CANVAS, then .circular-gallery, then .hero-gallery-stage
If you see `.hero-header` or `.window-container` first, the fix is not applied.

BUG 3 — A FRAME HITCH WHILE PASSING THROUGH THE WINDOW.
Cause: lazily mounting the gallery during the aperture scroll — creating the OGL canvas, compiling shaders, decoding images and uploading textures at the worst possible moment — and/or calling a React state setter from inside ScrollTrigger's `onUpdate`.
FIX: mount CircularGallery on the FIRST client render, invisible and parked below the viewport; `decode()` its images in a mount effect; drive everything afterwards through the imperative handle so no React reconciliation happens during scroll.
VERIFY: at scroll 0, `document.querySelectorAll('.hero-gallery-stage canvas').length === 1` and the gallery images already appear in `performance.getEntriesByType('resource')`. Then confirm ZERO new canvases and ZERO new resources appear as progress crosses the reveal threshold.

BUG 4 — A GALLERY CARD RENDERS AS A SOLID BLACK RECTANGLE.
Cause: a transparent PNG in the item list. The gallery's fragment shader samples the texture directly with no alpha compositing.
FIX: gallery images must be fully opaque. Never use /window.png as a card.

BUG 5 — THE APERTURE'S PIN DISTANCE IS WRONG AFTER A WINDOW RESIZE.
Cause: `end: \`+=${window.innerHeight * 5}px\`` as a static template string. It is evaluated once; `invalidateOnRefresh` does not recompute a literal.
FIX: `end: () => \`+=${window.innerHeight * 5}px\`` — a function IS re-evaluated on refresh.

BUG 6 — THE GALLERY SNAPS BACK TO THE SCROLL POSITION THE MOMENT YOU STOP DRAGGING.
Cause: the host writing straight to the gallery's internal `scroll.target`, so every scroll frame overwrites the user's drag.
FIX: split the target into two independent contributions inside the component —
  target = scrollBase + dragOffset
The host writes ONLY `scrollBase` (via `setScrollBase`). Pointer drags accumulate into `dragOffset` and are never touched by a host update. The release snap (`onCheck`) must also adjust `dragOffset`, never `scrollBase`.

BUG 7 — SCROLLING ANYWHERE ON THE PAGE SPINS THE GALLERY.
Cause: React Bits' CircularGallery attaches `wheel`/`mousewheel` listeners to `window`.
FIX: pass `captureWheel={false}`. Keep `capturePointer` so click-and-drag still works.

BUG 8 — TOUCH DRAG HIJACKS VERTICAL PAGE SCROLLING ON MOBILE.
Cause: claiming every touch pointer as a horizontal drag.
FIX: on a touch pointer, wait for an 8px movement threshold and only claim the gesture when |dx| > |dy|; otherwise release the pointer and let the page scroll. Never call `preventDefault()` on a vertical gesture. `.hero-gallery-stage` also sets `touch-action: pan-y`.

BUG 9 — A NEW SECTION IS CLIPPED TO EXACTLY ONE VIEWPORT.
Cause: the GLOBAL rule `section { height: 100svh; overflow: hidden }`. Every `<section>` inherits it.
FIX: every functional section sets `height: auto; min-height: 0; overflow: visible`. The global `h1` clamp cascades too — that is why every new section declares its own type sizes.

BUG 10 — THE GALLERY IS PINNED AT THE WRONG SCROLL POSITION (an earlier architecture).
Cause (historical, worth knowing): when a pinned section is created while other pinned sections above it have not registered yet, it measures its start against the wrong layout. PlaneOutro registers late because it waits for its GLB.
FIX in the current architecture: the gallery owns NO ScrollTrigger at all — it is driven by Hero's. If you ever add another pinned section below PlaneOutro, it needs `refreshPriority: -1` so it re-measures last.

BUG 11 — THE HERO COPY AND THE GALLERY OVERLAP UNREADABLY.
Cause: `.hero-copy` is `height:100svh; align-items:center`, i.e. a vertically centred block ~45svh tall. Centring the gallery too makes overlap mathematically unavoidable.
FIX, both halves: anchor the gallery to the TOP (`justify-content: flex-start`, `padding-top: calc(3svh + 33px)`, stage height `min(42svh, 380px)`), AND move the copy to the lower band (`.hero-copy { align-items: flex-end; padding-bottom: 6svh }`). Typography, size and the yPercent entry animation are untouched — only the resting position moves. Also give `.hero-gallery` `z-index: 0` (NOT a positive value) so the copy, a later z-auto sibling, still paints on top.

BUG 12 — DEV-ONLY: EFFECTS DOUBLE-FIRE AND LEAK.
Cause: React StrictMode double-invokes effects.
FIX: every effect returns a full cleanup — `ctx.revert()`, `gsap.ticker.remove(raf)`, `lenis.destroy()`, `cancelAnimationFrame`, `ScrollTrigger` kill via the gsap context, media-query listener removal, and the gallery's own `app.destroy()` which releases pointer capture, removes every listener and detaches its canvas.

"use client";

import { useEffect, useLayoutEffect, useRef, useState } from "react";

/**
 * Layout effect on the client, plain effect on the server render. This has to
 * run before Hero's own layout effect creates Lenis, which is why it cannot be
 * a regular useEffect.
 */
const useIsomorphicLayoutEffect =
  typeof window !== "undefined" ? useLayoutEffect : useEffect;

/**
 * Entry loader.
 *
 * The hero opens on two large plates (`sky.jpg` ~3 MB, `window.png` ~3.3 MB).
 * Until both are decoded the aperture cannot animate smoothly, so the page is
 * held behind a quiet cover in the site's own cold blue-white palette and its
 * own serif. It also gives the gallery's idle warm-up a moment to run.
 *
 * The loader is the one place a fade is wanted — it fades itself out and then
 * unmounts, leaving nothing behind.
 */

/** Blocking assets: the two plates the first frame of the hero depends on. */
const CRITICAL = ["/sky.jpg", "/window.png"];

/** Never hold the page longer than this, however slow the network is. */
const MAX_HOLD_MS = 6000;

export default function Loader() {
  const [progress, setProgress] = useState(0);
  const [done, setDone] = useState(false);
  const [gone, setGone] = useState(false);
  const doneRef = useRef(false);

  // A reload must always start the cinematic from the very beginning.
  //
  // Browsers restore the previous scroll position on refresh, which lands the
  // hero part-way through its pinned timeline — the window opens already
  // enlarged. Turning restoration off and resetting to the top has to happen
  // before Lenis is constructed in Hero's layout effect, otherwise Lenis
  // initialises at the restored offset.
  useIsomorphicLayoutEffect(() => {
    if ("scrollRestoration" in history) {
      history.scrollRestoration = "manual";
    }
    window.scrollTo(0, 0);
  }, []);

  // Belt and braces: if anything restored the offset while assets were still
  // loading, put it back before the cover comes off.
  useEffect(() => {
    if (!done) return;
    window.scrollTo(0, 0);
  }, [done]);

  useEffect(() => {
    let cancelled = false;
    let loaded = 0;

    const finish = () => {
      if (doneRef.current || cancelled) return;
      doneRef.current = true;
      setProgress(1);
      setDone(true);
    };

    const bump = () => {
      loaded += 1;
      if (cancelled) return;
      setProgress(loaded / CRITICAL.length);
      if (loaded >= CRITICAL.length) finish();
    };

    CRITICAL.forEach((src) => {
      const img = new Image();
      img.decoding = "async";
      img.src = src;
      // decode() resolves once the bitmap is ready to paint, not merely fetched
      img
        .decode()
        .then(bump)
        .catch(() => bump());
    });

    const guard = window.setTimeout(finish, MAX_HOLD_MS);
    return () => {
      cancelled = true;
      window.clearTimeout(guard);
    };
  }, []);

  // Unmount only after the fade has played, so nothing lingers in the DOM.
  useEffect(() => {
    if (!done) return;
    const t = window.setTimeout(() => setGone(true), 900);
    return () => window.clearTimeout(t);
  }, [done]);

  // No scroll lock here. Setting `overflow: hidden` on the document makes the
  // page unscrollable, which collapses ScrollTrigger's pin distance to zero and
  // leaves the hero stuck at the end of its timeline on first paint. The cover
  // is fixed and full-screen, so nothing needs locking anyway.

  if (gone) return null;

  return (
    <div className={`site-loader${done ? " is-done" : ""}`} aria-hidden={done}>
      <div className="site-loader-inner">
        <p className="site-loader-name">Yıldız Dikme</p>
        <p className="site-loader-role">Creative Developer</p>

        <div
          className="site-loader-track"
          role="progressbar"
          aria-valuemin={0}
          aria-valuemax={100}
          aria-valuenow={Math.round(progress * 100)}
        >
          <span
            className="site-loader-bar"
            style={{ transform: `scaleX(${progress})` }}
          />
        </div>
      </div>
    </div>
  );
}

"use client";

import { useLayoutEffect, useRef } from "react";
import gsap from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";
import Lenis from "lenis";
import HeroCircularGallery, {
  type HeroCircularGalleryHandle,
} from "./HeroCircularGallery";

gsap.registerPlugin(ScrollTrigger);

/**
 * The hero pin was 3 viewports; the gallery needs room to be explored, so it is
 * now 5. To keep the aperture looking exactly as it did, the window/header
 * motion is driven by `apertureProgress`, which replays the original 3-viewport
 * curve over the first 3 viewports of the longer pin — same scale, same
 * perspective, same rate of travel — and then holds.
 */
const PIN_VIEWPORTS = 5;
const APERTURE_VIEWPORTS = 3;
const APERTURE_SCALE = PIN_VIEWPORTS / APERTURE_VIEWPORTS;

/** Hero copy entry, remapped so it follows the gallery instead of preceding it. */
const COPY_START = 0.78;
/** Bottom fade into the plane section, kept clear of the gallery. */
const FADE_START = 0.78;
const FADE_SPAN = 0.12;

export default function Hero() {
  const rootRef = useRef<HTMLDivElement | null>(null);
  const fadeRef = useRef<HTMLDivElement | null>(null);
  const galleryRef = useRef<HeroCircularGalleryHandle | null>(null);

  useLayoutEffect(() => {
    if (!rootRef.current) return;

    const lenis = new Lenis();

    /**
     * A reload must always start the cinematic from the very beginning.
     *
     * The browser can restore the previous scroll offset, and once Lenis is
     * running it writes its own position back to the document every frame — so
     * a plain `window.scrollTo(0, 0)` is overwritten on the next tick and the
     * aperture opens already enlarged. The reset therefore has to go through
     * Lenis itself. Repeated once on the next frame in case the browser
     * restores the offset immediately after mount.
     */
    const resetToStart = () =>
      lenis.scrollTo(0, { immediate: true, force: true });

    resetToStart();
    const resetRaf = requestAnimationFrame(resetToStart);

    const raf = (time: number) => {
      lenis.raf(time * 1000);
    };

    lenis.on("scroll", ScrollTrigger.update);
    gsap.ticker.add(raf);
    gsap.ticker.lagSmoothing(0);

    const ctx = gsap.context(() => {
      const windowContainer = document.querySelector(".window-container");
      const skyContainer = document.querySelector(".sky-container");
      const heroCopy = document.querySelector(".hero-copy");
      const heroHeader = document.querySelector(".hero-header");
      const hero = document.querySelector(".hero");

      if (
        !windowContainer ||
        !skyContainer ||
        !heroCopy ||
        !heroHeader ||
        !hero
      )
        return;

      const skyContainerHeight = (skyContainer as HTMLElement).offsetHeight;
      const viewportHeight = window.innerHeight;
      const skyMoveDistance = skyContainerHeight - viewportHeight;

      // ✅ İlk frame flash’ini öldür: önce görünmez, sonra GSAP kontrolüne al
      gsap.set(heroCopy, { yPercent: 100, autoAlpha: 1 });

      ScrollTrigger.create({
        trigger: hero,
        start: "top top",
        end: () => `+=${window.innerHeight * PIN_VIEWPORTS}px`,
        pin: true,
        pinSpacing: true,
        scrub: 1,
        invalidateOnRefresh: true,
        onUpdate: (self) => {
          const progress = self.progress;

          // Original 3-viewport aperture curve, replayed over the first 3 of 5.
          const ap = Math.min(1, progress * APERTURE_SCALE);

          // window scale — unchanged formula, unchanged absolute rate
          const windowScale = ap <= 0.5 ? 1 + (ap / 0.5) * 3 : 4;

          gsap.set(windowContainer, { scale: windowScale });
          gsap.set(heroHeader, { scale: windowScale, z: ap * 500 });

          // sky move — spread across the full pin so the clouds keep drifting
          // gently behind the gallery instead of freezing partway through
          gsap.set(skyContainer, { y: -progress * skyMoveDistance });

          // hero copy y — now enters after the gallery has left
          let heroCopyY: number;
          if (progress <= COPY_START) {
            heroCopyY = 100;
          } else if (progress >= 1) {
            heroCopyY = 0;
          } else {
            heroCopyY = 100 * (1 - (progress - COPY_START) / (1 - COPY_START));
          }

          gsap.set(heroCopy, { yPercent: heroCopyY });

          // fade overlay
          if (fadeRef.current) {
            const fade = gsap.utils.clamp(
              0,
              1,
              (progress - FADE_START) / FADE_SPAN,
            );
            gsap.set(fadeRef.current, { opacity: fade });
          }

          // Gallery overlay — revealed off the aperture's own scale, then
          // visible for the rest of the Hero. Imperative: no React state.
          galleryRef.current?.update(progress);
        },
      });

      ScrollTrigger.refresh();
    }, rootRef);

    return () => {
      cancelAnimationFrame(resetRaf);
      ctx.revert();
      gsap.ticker.remove(raf);
      lenis.destroy();
    };
  }, []);

  return (
    <div ref={rootRef}>
      <section className="hero">
        <div className="hero-fade" ref={fadeRef} />

        <div className="sky-container">
          <img src="/sky.jpg" alt="" />
        </div>

        {/* Overlay inside the pinned hero. Sits between the clouds and the
            hero copy, so the copy always reads on top of it. The window is
            painted after it — the glass is fully transparent, so at full
            aperture the gallery shows straight through. */}
        <HeroCircularGallery ref={galleryRef} />

        <div className="hero-copy">
          <h1>
            What I build isn’t a page, but a passage. A sustained calm where
            noise fades, edges soften, and attention holds a little longer than
            expected. The interface stays steady while everything around it
            keeps moving.
          </h1>
        </div>

        <div className="window-container">
          <img src="/window.png" alt="" />
        </div>

        <div className="hero-header">
          <div className="col">
            <h1>
              Yıldız <br />
              Dikme
            </h1>
            <p>
              A practice suspended between craft and code. Interfaces, products,
              and three-dimensional work—shaped with intent, built to be felt
              before they are explained.
            </p>
          </div>

          <div className="col">
            <p>Creative Developer</p>
            <h1>
              Where ideas <br />
              become interfaces
            </h1>
          </div>
        </div>
      </section>

    </div>
  );
}

──────── C.11  app/HeroCircularGallery.tsx   *** THE BRIDGE *** ────────
"use client";

import {
  forwardRef,
  useCallback,
  useEffect,
  useImperativeHandle,
  useRef,
  useSyncExternalStore,
} from "react";
import CircularGallery, {
  type CircularGalleryApi,
} from "@/components/CircularGallery";

/**
 * The gallery layer inside the Hero aperture sequence.
 *
 * This is NOT a page section. It is an overlay rendered inside the pinned
 * `.hero`, above the cloud background and below the existing hero copy.
 *
 * Lifecycle:
 *  - mounted and fully warmed (canvas, shaders, decoded textures) during idle
 *    time right after the page settles, while still invisible
 *  - revealed in a single step once the aperture is nearly complete — no fade,
 *    no scale, no transform animation of the wrapper
 *  - stays visible and interactive for the rest of the Hero, leaving only when
 *    the Hero itself unpins into PlaneOutro
 *
 * Hero calls `update()` every scroll frame. That path touches inline styles and
 * the imperative gallery API only — it never sets React state.
 */

/* ---------------------------------------------------------------------------
 * Gallery items — edit freely.
 *
 * PLACEHOLDERS: only `Asteroid Bloom` is a real piece of work. The rest reuse
 * assets that already ship with this site so the curve has enough distinct
 * cards to read as a gallery. Swap them for real project stills; do not present
 * them as client work.
 *
 * Note: images must be fully opaque. The gallery shader samples the texture
 * directly, so a PNG with transparency (e.g. /window.png) renders as a black
 * rectangle rather than compositing over the clouds.
 * ------------------------------------------------------------------------- */
const GALLERY_ITEMS = [
  { image: "/media/asteroid/still-desktop.webp", text: "Asteroid Bloom" },
  { image: "/sky.jpg", text: "Placeholder — Sky Study" },
  { image: "/media/asteroid/poster-desktop.webp", text: "Placeholder — Pre-Bloom" },
  { image: "/sky2.jpg", text: "Placeholder — Horizon" },
];

/*
 * Entrance. The gallery rises into place exactly the way the hero copy does —
 * it starts fully below the viewport and slides up as the visitor scrolls,
 * so it is never "popped" into an empty cloud scene.
 *
 *   0.30  the aperture has finished (window scale 4); the gallery is still
 *         entirely off-screen below, so nothing appears out of nowhere
 *   0.48  fully in place
 *   then  it stays there for the rest of the Hero — no fade, no exit
 *
 * Opacity is 1 the whole time. The only thing that moves is position.
 */
const ENTER_START = 0.3;
const ENTER_END = 0.48;

/** How many item-widths the vertical scroll advances once it is in place. */
const ITEMS_TRAVELLED = 5;

/** Conservative caps — this page already runs a second WebGL context. */
const DPR_DESKTOP = 1.5;
const DPR_MOBILE = 1;

function useMediaQuery(query: string) {
  const subscribe = useCallback(
    (onChange: () => void) => {
      const mq = window.matchMedia(query);
      mq.addEventListener("change", onChange);
      return () => mq.removeEventListener("change", onChange);
    },
    [query],
  );

  return useSyncExternalStore(
    subscribe,
    () => window.matchMedia(query).matches,
    () => false,
  );
}

export type HeroCircularGalleryHandle = {
  /** Called from Hero's existing ScrollTrigger onUpdate. */
  update: (progress: number) => void;
};

const HeroCircularGallery = forwardRef<HeroCircularGalleryHandle>(
  function HeroCircularGallery(_props, ref) {
    const wrapRef = useRef<HTMLDivElement | null>(null);
    const apiRef = useRef<CircularGalleryApi | null>(null);
    /** Mirrors the current visibility so we only touch the DOM on a change. */
    const shownRef = useRef(false);

    const isMobile = useMediaQuery("(max-width: 900px)");
    const reducedMotion = useMediaQuery("(prefers-reduced-motion: reduce)");

    // Images are requested on the very first client render, alongside the
    // renderer below. Everything therefore loads behind the entry loader, and
    // nothing at all is created once the visitor starts scrolling.
    useEffect(() => {
      if (reducedMotion) return;
      GALLERY_ITEMS.forEach((item) => {
        const img = new Image();
        img.decoding = "async";
        img.src = item.image;
        void img.decode().catch(() => undefined);
      });
    }, [reducedMotion]);

    useImperativeHandle(
      ref,
      () => ({
        update(progress: number) {
          const wrap = wrapRef.current;
          if (!wrap) return;

          const clamp01 = (v: number) => (v < 0 ? 0 : v > 1 ? 1 : v);
          const slide = clamp01(
            (progress - ENTER_START) / (ENTER_END - ENTER_START),
          );

          // Position only — opacity stays at 1 and is never animated.
          wrap.style.transform = `translateY(${((1 - slide) * 100).toFixed(2)}svh)`;

          // Visibility is the only binary, and it flips while the gallery is
          // still completely off-screen, so it can never appear abruptly.
          const shouldShow = progress >= ENTER_START;
          if (shouldShow !== shownRef.current) {
            shownRef.current = shouldShow;
            wrap.style.visibility = shouldShow ? "visible" : "hidden";
          }

          // Dragging is live once it has settled into place.
          const interactive = slide >= 1;
          wrap.style.pointerEvents = interactive ? "auto" : "none";

          if (!shouldShow || reducedMotion) return;

          const api = apiRef.current;
          if (!api) return;

          // Items advance from the moment it lands to the end of the Hero. The
          // user's drag offset lives inside the gallery and is added on top, so
          // scrolling never cancels a drag.
          const span = Math.max(0.0001, 1 - ENTER_END);
          const travel = clamp01((progress - ENTER_END) / span);
          const width = api.getItemWidth();
          if (width > 0) api.setScrollBase(travel * ITEMS_TRAVELLED * width);
        },
      }),
      [reducedMotion],
    );

    return (
      <div className="hero-gallery" ref={wrapRef}>
        <div className="hero-gallery-stage">
          {reducedMotion && (
            <div className="hero-gallery-static">
              {GALLERY_ITEMS.slice(0, 3).map((item) => (
                <figure key={item.text}>
                  {/* eslint-disable-next-line @next/next/no-img-element */}
                  <img src={item.image} alt="" decoding="async" />
                  <figcaption>{item.text}</figcaption>
                </figure>
              ))}
            </div>
          )}

          {!reducedMotion && (
            <CircularGallery
              items={GALLERY_ITEMS}
              bend={isMobile ? 2 : 3}
              textColor="#12212a"
              borderRadius={0.03}
              scrollEase={0.06}
              dpr={isMobile ? DPR_MOBILE : DPR_DESKTOP}
              // Wheel capture stays off — upstream listens on window and would
              // spin the gallery on every scroll anywhere on the page while
              // fighting Lenis. Pointer dragging stays on, scoped to the
              // container, so the original click-and-drag interaction works.
              captureWheel={false}
              capturePointer
              apiRef={apiRef}
            />
          )}
        </div>
      </div>
    );
  },
);

export default HeroCircularGallery;

    const clone = scene.clone(true);

    // rotation önce (bounding box doğru ölçülsün)
    clone.rotation.set(-Math.PI / 2, 0, Math.PI);

    // ✅ Prod/dev farkını bitiren normalize
    clone.updateMatrixWorld(true);
    const box = new THREE.Box3().setFromObject(clone);
    const size = new THREE.Vector3();
    box.getSize(size);

    const maxDim = Math.max(size.x, size.y, size.z);

    // ✅ Desktopta şu anki görünümüne yakın bir hedef seçtik.
    // Eğer hala çok büyük/küçük gelirse sadece TARGET ile oynarsın.
    const TARGET = 10;

    const normalizeScale = maxDim > 0 ? TARGET / maxDim : 1;

    // ✅ Desktop/mobil oranını BOZMADAN koru
    const DESKTOP_FACTOR = 0.9;
    const MOBILE_FACTOR = 0.75;

    clone.scale.setScalar(
      normalizeScale * (isMobile ? MOBILE_FACTOR : DESKTOP_FACTOR),
    );

    return clone;
  }, [scene, isMobile]);

  useLayoutEffect(() => {
    if (!prepared) return;
    onReady();
  }, [prepared, onReady]);

  if (!prepared) return null;
  return <primitive ref={planeRef} object={prepared} />;
}

export default function PlaneOutro() {
  const sectionRef = useRef<HTMLElement | null>(null);
  const planeRef = useRef<THREE.Group | null>(null);
  const leftTextRef = useRef<HTMLDivElement | null>(null);
  const rightTextRef = useRef<HTMLDivElement | null>(null);
  const bgFadeRef = useRef<HTMLDivElement | null>(null);

  const [isPlaneReady, setIsPlaneReady] = useState(false);

  const [isMobile, setIsMobile] = useState(false);
  useLayoutEffect(() => {
    const mq = window.matchMedia("(max-width: 900px)");
    const update = () => setIsMobile(mq.matches);
    update();
    mq.addEventListener?.("change", update);
    return () => mq.removeEventListener?.("change", update);
  }, []);

  useLayoutEffect(() => {
    if (!sectionRef.current) return;
    if (!isPlaneReady) return;
    if (!planeRef.current) return;

    const START_OFFSET = -18;
    const END_OFFSET = 12;

    const ctx = gsap.context(() => {
      // start pose
      planeRef.current!.position.y = BASE_Y + START_OFFSET;

      if (leftTextRef.current)
        gsap.set(leftTextRef.current, { y: 80, opacity: 0 });
      if (rightTextRef.current)
        gsap.set(rightTextRef.current, { y: 80, opacity: 0 });

      const toPlaneY = gsap.quickTo(planeRef.current!.position, "y", {
        duration: 0.9,
        ease: "power3.out",
        overwrite: true,
      });

      const toLeftY = leftTextRef.current
        ? gsap.quickTo(leftTextRef.current, "y", {
            duration: 0.6,
            ease: "power3.out",
            overwrite: true,
          })
        : null;

      const toLeftOpacity = leftTextRef.current
        ? gsap.quickTo(leftTextRef.current, "opacity", {
            duration: 0.6,
            ease: "power2.out",
            overwrite: true,
          })
        : null;

      const toRightY = rightTextRef.current
        ? gsap.quickTo(rightTextRef.current, "y", {
            duration: 0.6,
            ease: "power3.out",
            overwrite: true,
          })
        : null;

      const toRightOpacity = rightTextRef.current
        ? gsap.quickTo(rightTextRef.current, "opacity", {
            duration: 0.6,
            ease: "power2.out",
            overwrite: true,
          })
        : null;

      const toBg = bgFadeRef.current
        ? gsap.quickTo(bgFadeRef.current, "opacity", {
            duration: 0.35,
            ease: "power2.out",
            overwrite: true,
          })
        : null;

      const st = ScrollTrigger.create({
        trigger: sectionRef.current!,
        start: "top top",
        end: "+=180%",
        pin: true,
        pinSpacing: true,
        anticipatePin: 1,
        invalidateOnRefresh: true,

        onUpdate: (self) => {
          const p = self.progress; // 0..1

          const targetY = gsap.utils.interpolate(
            BASE_Y + START_OFFSET,
            BASE_Y + END_OFFSET,
            p,
          );
          toPlaneY(targetY);

          const leftP = gsap.utils.clamp(0, 1, (p - 0.08) / 0.2);
          if (toLeftY) toLeftY(gsap.utils.interpolate(80, 0, leftP));
          if (toLeftOpacity) toLeftOpacity(leftP);

          const rightP = gsap.utils.clamp(0, 1, (p - 0.12) / 0.2);
          if (toRightY) toRightY(gsap.utils.interpolate(80, 0, rightP));
          if (toRightOpacity) toRightOpacity(rightP);

          const bgP = gsap.utils.clamp(0, 1, (p - 0.72) / 0.28);
          if (toBg) toBg(bgP);

          const textP = gsap.utils.clamp(0, 1, (p - 0.78) / 0.22);
          const rr = Math.round(15 + (255 - 15) * textP);
          const gg = Math.round(15 + (255 - 15) * textP);
          const bb = Math.round(15 + (255 - 15) * textP);

          document.documentElement.style.setProperty(
            "--plane-text-color",
            `rgb(${rr},${gg},${bb})`,
          );
        },
      });

      return () => st.kill();
    }, sectionRef);

    return () => ctx.revert();
  }, [isPlaneReady]);

  // Kamera: aynen korunuyor
  const cameraPosition = isMobile
    ? ([0, 5.2, 26] as const)
    : ([0, 4.4, 15] as const);
  const cameraFov = isMobile ? 42 : 28;

  return (
    <section
      ref={sectionRef}
      className="plane-section relative z-10"
      style={{ boxShadow: "0 160px 140px -80px rgba(0,0,0,0.95)" }}
    >
      <div className="plane-wrapper">
        <div
          ref={bgFadeRef}
          className="pointer-events-none absolute inset-0 z-[1] bg-[#0b0b0c] opacity-0"
          aria-hidden
        />

        <div className="left-text" ref={leftTextRef}>
          <h2>Creative</h2>
          <p>Digital work that moves with intent</p>
        </div>

        <div className="right-text" ref={rightTextRef}>
          <h2>Technology</h2>
        </div>

        <Canvas
          className="plane-canvas"
          dpr={[1, 1.5]}
          camera={{ position: cameraPosition, fov: cameraFov }}
        >
          <ambientLight intensity={1.1} />
          <directionalLight position={[6, 10, 8]} intensity={2.2} />
          <directionalLight position={[-6, 8, 6]} intensity={1.0} />
          <Suspense fallback={null}>
            <PlaneModel
              planeRef={planeRef}
              onReady={() => setIsPlaneReady(true)}
              isMobile={isMobile}
            />
          </Suspense>
        </Canvas>
      </div>
    </section>
  );
}

STEP 2 — apply exactly these local adaptations. Nothing else in the file changes:
the render loop, the easing, the shaders, the bend/arc maths and the title
rendering are all untouched, which is what preserves the original drag feel.

  1. Add `'use client';` as the very first line. The component touches
     window/document on mount.

  2. Split upstream's single input path into two independent flags. Add to both
     `AppConfig` and `CircularGalleryProps`:
         captureWheel?: boolean    // default true
         capturePointer?: boolean  // default true
     Store both on the App instance. In addEventListeners(), `resize` is ALWAYS
     attached to window; the wheel listeners are attached only when
     `captureWheel`; the pointer listeners only when `capturePointer`.
     Rationale: this host uses Lenis and a pinned GSAP timeline, so window-level
     wheel capture must be off while pointer dragging stays on.

  3. Replace the window-level mouse/touch drag with Pointer Events scoped to the
     CONTAINER element. Delete onTouchDown/onTouchMove/onTouchUp; add:
         onPointerDown / onPointerMove / onPointerUp / releasePointer / capturePointerId
     and register on the container: pointerdown, pointermove, pointerup,
     pointercancel, lostpointercapture, keydown.
     - A mouse press is claimed immediately (`gestureResolved = true`) and only
       for `button === 0`.
     - A TOUCH pointer is NOT claimed until the gesture proves horizontal: wait
       until |dx| or |dy| exceeds 8px, then claim only if |dx| > |dy|, otherwise
       call releasePointer and let the page scroll.
     - Hold pointer capture only for the duration of a drag; wrap
       setPointerCapture / hasPointerCapture / releasePointerCapture in
       try/catch (they throw if the pointer is already gone).
     - preventDefault() is NEVER called anywhere.

  4. Split the scroll target into two independent contributions. Add to App:
         scrollBase: number = 0     // written by the host
         dragOffset: number = 0     // accumulated by the user
         applyTarget() { this.scroll.target = this.scrollBase + this.dragOffset }
     - onPointerMove: `dragOffset = dragStartOffset - dx * (scrollSpeed * 0.025)` then applyTarget()
     - onWheel (when captureWheel is on): accumulate into `dragOffset`, then applyTarget()
     - onKeyDown Arrow keys: accumulate into `dragOffset`, then applyTarget()
     - onCheck() (the release snap) computes `raw = scrollBase + dragOffset`,
       snaps `raw` to the nearest item width, then sets
       `dragOffset = snapped - scrollBase`. It must NEVER write scrollBase.

  5. Add a `dpr?: number` prop, threaded to the renderer:
         dpr: Math.min(window.devicePixelRatio || 1, this.dpr ?? 2)
     Upstream's hard-coded cap of 2 becomes the default.

  6. Expose an imperative handle. Add and export:
         export interface CircularGalleryApi {
           setScrollBase: (base: number) => void;
           getItemWidth: () => number;
           isDragging: () => boolean;
         }
     Add an `apiRef?: React.MutableRefObject<CircularGalleryApi | null>` prop and
     populate it once the renderer is live, inside the same `.then()` that
     constructs the App. Null it out in the effect's cleanup. Add the three
     methods to App: setScrollBase(base) { this.scrollBase = base; this.applyTarget() },
     getItemWidth() { return this.medias?.[0]?.width ?? 0 }, isDragging() { return this.isDown }.

  7. Extend the effect's dependency array with captureWheel, capturePointer, dpr
     and apiRef. Keep it a CONSTANT length across renders — a dependency array
     that changes size between renders is a React error.

  8. destroy() must release any held pointer capture, remove the container
     listeners (not window ones) for the pointer events, remove the window
     wheel/resize listeners, and detach the canvas.

import { useEffect, useRef } from "react"
import createGlobe, { type COBEOptions } from "cobe"
import { useMotionValue, useSpring } from "motion/react"
import { cn } from "@/lib/utils"

const MOVEMENT_DAMPING = 1400

const DEFAULT_CONFIG: COBEOptions = {
  width: 1200,
  height: 1200,
  onRender: () => {},
  devicePixelRatio: 2,
  phi: 0,
  theta: 0.3,
  dark: 1,
  diffuse: 0.35,
  mapSamples: 16000,
  mapBrightness: 1.0,
  baseColor: [1, 1, 1],
  markerColor: [251 / 255, 100 / 255, 21 / 255],
  glowColor: [0.85, 0.85, 0.85],
  markers: [
    { location: [14.5995, 120.9842], size: 0.03 },
    { location: [19.076, 72.8777], size: 0.1 },
    { location: [23.8103, 90.4125], size: 0.05 },
    { location: [30.0444, 31.2357], size: 0.07 },
    { location: [39.9042, 116.4074], size: 0.08 },
    { location: [-23.5505, -46.6333], size: 0.1 },
    { location: [19.4326, -99.1332], size: 0.1 },
    { location: [40.7128, -74.006], size: 0.1 },
    { location: [34.6937, 135.5022], size: 0.05 },
    { location: [41.0082, 28.9784], size: 0.06 },
  ],
}

export function Globe({
  className,
  config = DEFAULT_CONFIG,
}: {
  className?: string
  config?: COBEOptions
}) {
  const canvasRef = useRef<HTMLCanvasElement>(null)
  const pointerInteracting = useRef<number | null>(null)
  const pointerInteractionMovement = useRef(0)

  const r = useMotionValue(0)
  const rs = useSpring(r, { mass: 1, damping: 30, stiffness: 100 })

  const updatePointerInteraction = (value: number | null) => {
    pointerInteracting.current = value
    if (canvasRef.current) {
      canvasRef.current.style.cursor = value !== null ? "grabbing" : "grab"
    }
  }

  const updateMovement = (clientX: number) => {
    if (pointerInteracting.current !== null) {
      const delta = clientX - pointerInteracting.current
      pointerInteractionMovement.current = delta
      r.set(r.get() + delta / MOVEMENT_DAMPING)
    }
  }

  useEffect(() => {
    const canvas = canvasRef.current
    if (!canvas) return

    let phi = 0
    let width = 0

    const onResize = () => {
      width = canvas.offsetWidth || 1
    }

    window.addEventListener("resize", onResize)
    onResize()

    const globe = createGlobe(canvas, {
      ...config,
      width: Math.floor(width * 2),
      height: Math.floor(width * 2),
      onRender: (state) => {
        if (!pointerInteracting.current) phi += 0.005
        state.phi = phi + rs.get()
        state.width = Math.floor(width * 2)
        state.height = Math.floor(width * 2)
      },
    })

    // fade-in
    requestAnimationFrame(() => {
      if (canvasRef.current) canvasRef.current.style.opacity = "1"
    })

    return () => {
      globe.destroy()
      window.removeEventListener("resize", onResize)
    }
  }, [rs, config])

  return (
    <div
      className={cn(
        // ✅ artık max-w yok -> parent ne verirse o kadar büyür
        "absolute inset-0 mx-auto aspect-square w-full [contain:layout_paint_size]",
        className
      )}
    >
      <canvas
        ref={canvasRef}
        className="size-full opacity-0 transition-opacity duration-500"
        onPointerDown={(e) => updatePointerInteraction(e.clientX)}
        onPointerUp={() => updatePointerInteraction(null)}
        onPointerOut={() => updatePointerInteraction(null)}
        onMouseMove={(e) => updateMovement(e.clientX)}
        onTouchMove={(e) => e.touches[0] && updateMovement(e.touches[0].clientX)}
      />
    </div>
  )
}
